# Roadmap Publikator

## Текущая базовая версия

Рабочий модульный монолит: Docker, Fastify, SQLite/WAL, media storage, embedded scheduler, Telegram/VK/MAX/Instagram adapters, явный выбор целевых аккаунтов, retry/recovery и журнал событий.

## Следующие этапы

1. Удобные формы подключения площадок вместо ручного JSON credentials.
2. Проверка соединения с площадкой до сохранения аккаунта.
3. Platform-specific preview и отдельный текст для каждой площадки.
4. Instagram carousel и расширенная медиавалидация по требованиям площадок.
5. Импорт контент-плана из CSV/XLSX/Google Sheets как необязательная функция, без превращения внешней таблицы в runtime-зависимость.
6. Полный backup bundle: SQLite + media + metadata с восстановлением через UI.
7. E2E-тесты CRUD/scheduler на временной SQLite и mock-адаптерах.
8. Статистика публикаций там, где официальные API позволяют получать её стабильно.

Любой новый инфраструктурный компонент требует ADR и не должен нарушать правило одного production-контейнера без доказанной необходимости.
