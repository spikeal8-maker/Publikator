# Настройки ИИ в Publikator

[AI-SETTINGS-001](https://github.com/spikeal8-maker/Publikator/issues/270) развивает [операторский контракт](CANONICAL_OPERATOR_UI_FUNCTIONAL_SPEC.md), [контракт чата](OWNER_MCP_CHAT_001.md) и [модель полномочий](AGENT_ACCESS_LEVELS_AND_ACTIVITY_LOGS.md).

| Вкладка | Что делает владелец |
| --- | --- |
| Обзор | Видит модели, результаты проверок и состояние адреса MCP. Выбирает модель по умолчанию для этого браузера. |
| Локальные модели | Видит список подключений. Добавляет отдельную запись для каждого сервера Ollama или llama.cpp и выбирает его модель. Адрес проверяется с сервера Publikator. Ollama показывает адрес и модели, полученные с этого адреса. Имена существующих подключений и настроенные ключи сохраняются. |
| Облачные модели | Добавляет OpenAI, DeepSeek или совместимый HTTPS API отдельными кнопками. OpenAI и DeepSeek используют заданные адреса. |
| MCP | Находит адрес для внешнего ChatGPT и инструкцию OAuth. Отдельно управляет административными ключами доверенных клиентов. |
| Доступы | Выбирает действия и ресурсы внешнего ChatGPT. Видит режим встроенного помощника. Журнал доступен в консоли. |

Интерфейс подключения и диагностика описаны в [AI-SETTINGS-003](https://github.com/spikeal8-maker/Publikator/issues/277).

## Работа в чате

Над перепиской виден выбор «Модель чата». В списке только включённые подключения, сгруппированные по типу. Следующее сообщение использует выбранное подключение. Модель можно менять в существующем диалоге.

Встроенный чат передаёт сообщения выбранной модели. MCP даёт внешнему клиенту инструменты Publikator. Эти подключения используют разные адреса и учётные данные.

При подключении форма сама запрашивает список моделей. Кнопка «Проверить и сохранить» отправляет безопасный пробный запрос с введёнными параметрами. Ошибка сети, адреса или ключа сохраняется на экране и не заменяет рабочую запись. Ответ без вызова инструмента сохраняется с соответствующим статусом. [AI-SETTINGS-005](https://github.com/spikeal8-maker/Publikator/issues/281)

Для Ollama можно ввести `адрес:порт` или полный URL. Если адрес введён без схемы и порта, используется HTTP и стандартный порт 11434. Если сервер вернул одну модель, она выбирается сразу. При нескольких моделях пользователь выбирает одну из списка. Сохранённая модель выбирается при редактировании только если сервер по-прежнему её возвращает. [AI-SETTINGS-006](https://github.com/spikeal8-maker/Publikator/issues/283)

## Полномочия

Первый этап перестраивает интерфейс и сохраняет ранее выданные полномочия. Опция «Разрешить действия» управляет одним запуском встроенного чата. Режим каждой модели ограничивает перечень и исполнение инструментов. Выбор отдельных ресурсов и наборов инструментов остаётся отдельным этапом. Новые модели не получают автоматически права внешнего ChatGPT. Отправка публикаций подчиняется модели грантов и согласования владельцем.

llama.cpp поддерживается через `/v1/models` и `/v1/chat/completions`. Подключение предназначено для локальной сети и Tailscale. Publikator проверяет вызов инструмента на выбранной модели. Для него нужен поддерживаемый llama.cpp шаблон чата. [AI-SETTINGS-004](https://github.com/spikeal8-maker/Publikator/issues/279) · [Документация llama.cpp](https://github.com/ggml-org/llama.cpp/blob/master/tools/server/README.md)

## Приёмка

- Вкладки доступны мышью, с клавиатуры и на узком экране.
- Ollama получает модели по введённому адресу, сохраняет выбор и выполняет тест инструмента.
- Облачные формы OpenAI и DeepSeek запрашивают ключ и показывают подключения своего раздела. Второй сервер Ollama сохраняется отдельно. Ошибка адреса или проверки видна в форме.
- Модель по умолчанию сохраняется в браузере. Выбор в чате применяется к следующему сообщению.
- Журнал, ключи и права ChatGPT доступны в своих разделах. Существующие подключения и OAuth-гранты сохранены.

## Права каждой модели

Во вкладке «Доступы» владелец выбирает подключение Ollama или облачного API и задаёт «Только чтение» либо «Чтение и действия». В первом режиме сервер исключает инструменты записи и проверяет каждый вызов. Во втором флажок «Разрешить действия» управляет отдельным сообщением. Изменение политики обновляет версию подключения, поэтому выполняющийся диалог прекращает новые действия. При переходе к действиям интерфейс показывает отдельное подтверждение.

## Консоль Publikator

Кнопка «Консоль» показывает версию, схему, краткую сводку очереди и последние операции. Встроенный помощник получает тот же статус через `publikator_system_status`. Для доработки владелец или модель готовят описание с фактами и проверкой через `publikator_prepare_change_draft`. Черновик копируется в GitHub по решению владельца. Изменения исходников проходят через ветку, PR и Acceptance. Для работы с экземпляром на сервере используются разрешённые действия 1Panel. [AI-CONSOLE-001](https://github.com/spikeal8-maker/Publikator/issues/274)
