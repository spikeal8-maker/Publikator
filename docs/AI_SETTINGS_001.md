# Настройки ИИ в Publikator

[AI-SETTINGS-001](https://github.com/spikeal8-maker/Publikator/issues/270) развивает [операторский контракт](CANONICAL_OPERATOR_UI_FUNCTIONAL_SPEC.md), [контракт чата](OWNER_MCP_CHAT_001.md) и [модель полномочий](AGENT_ACCESS_LEVELS_AND_ACTIVITY_LOGS.md).

| Вкладка | Что делает владелец |
| --- | --- |
| Общие | Выбирает модель по умолчанию для этого браузера. |
| Локальные модели | Сохраняет Ollama на сервере или соседнем компьютере. Вводит сетевой адрес, выбирает модель и проверяет вызов инструмента. |
| Облачные API | Сохраняет OpenAI, DeepSeek или совместимый HTTPS API. Вводит ключ провайдера и выбирает модель. |
| MCP | Находит адрес для внешнего ChatGPT и инструкцию OAuth. Отдельно управляет административными ключами доверенных клиентов. |
| Доступы | Выбирает действия и ресурсы внешнего ChatGPT. Видит режим встроенного помощника и последние действия. |

## Работа в чате

Над перепиской виден выбор «Модель чата». В списке только включённые подключения, сгруппированные по типу. Следующее сообщение использует выбранное подключение. Модель можно менять в существующем диалоге.

Встроенный чат передаёт сообщения выбранной модели. MCP даёт внешнему клиенту инструменты Publikator. Эти подключения используют разные адреса и учётные данные.

## Полномочия

Первый этап перестраивает интерфейс и сохраняет ранее выданные полномочия. Опция «Разрешить действия» управляет одним запуском встроенного чата. Режим каждой модели ограничивает перечень и исполнение инструментов. Выбор отдельных ресурсов и наборов инструментов остаётся отдельным этапом. Новые модели не получают автоматически права внешнего ChatGPT. Отправка публикаций подчиняется модели грантов и согласования владельцем.

Добавление новых локальных серверов моделей требует проверки их протокола, обнаружения моделей и вызова инструментов. Сетевые ограничения и хранение ключей определяются существующим контрактом.

## Приёмка

- Вкладки доступны мышью, с клавиатуры и на узком экране.
- Ollama получает модели по введённому адресу, сохраняет выбор и выполняет тест инструмента.
- Облачная форма запрашивает ключ и показывает подключения своего раздела.
- Модель по умолчанию сохраняется в браузере. Выбор в чате применяется к следующему сообщению.
- Журнал, ключи и права ChatGPT доступны в своих разделах. Существующие подключения и OAuth-гранты сохранены.

## Права каждой модели

Во вкладке «Доступы» владелец выбирает подключение Ollama или облачного API и задаёт «Только чтение» либо «Чтение и действия». В первом режиме сервер исключает инструменты записи и проверяет каждый вызов. Во втором флажок «Разрешить действия» управляет отдельным сообщением. Изменение политики обновляет версию подключения, поэтому выполняющийся диалог прекращает новые действия. При переходе к действиям интерфейс показывает отдельное подтверждение.
