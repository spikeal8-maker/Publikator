Подключения и MCP

Подключения моделей

Сначала выберите провайдер и адрес. Список моделей подгружается с сервера автоматически. Затем проверьте, что выбранная модель умеет вызывать инструменты. API-ключи сохраняются зашифрованными.

Ollama определяет установленные модели через сервер, в том числе на другом компьютере локальной сети.

Модели будут получены с выбранного сервера автоматически.

Модель не появилась в списке?

Только для API, не поддерживающих список моделей. В обычной ситуации вводить имя не требуется.

Доступ внешнего бота по MCP

Создайте отдельный ключ для каждого доверенного бота. Ключ даёт административное управление Publikator; отключить его можно в любой момент.

MCP Publikator уже работает локально. Подключение именно из ChatGPT требует HTTPS либо Secure MCP Tunnel и настройки вашего аккаунта ChatGPT.

Как подключить Publikator напрямую к ChatGPT

В ChatGPT откройте Plugins → + → Add custom MCP server. Для частного D2-R2 выберите Secure MCP Tunnel, укажите выданный в OpenAI Platform tunnel_id и настройте аутентификацию. Затем проверьте обнаруженные инструменты. Если доступен внешний HTTPS-адрес, вместо Tunnel укажите его с /mcp.

Нужны права вашего аккаунта на создание собственного MCP-подключения. В ChatGPT доступность действий записи зависит от рабочего пространства. Локальный адрес 127.0.0.1 недоступен облачному ChatGPT.
