Подключения и MCP

Модель для чата

Вставьте свой API-ключ или подключите Ollama. Ключ хранится зашифрованным и не передаётся в переписку.

Доступ внешнего бота по MCP

Создайте отдельный ключ для каждого доверенного бота. Ключ даёт административное управление Publikator; отключить его можно в любой момент.

Подключение по Bearer-ключу. Для клиента на другом компьютере нужен защищённый сетевой адрес сервера. OAuth-подключение облачного ChatGPT не настроено.

Скопируйте ключ сейчас — повторно он не показывается.
