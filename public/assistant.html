Новый диалог

Что нужно сделать?

Попросите проверить публикации, подготовить материал с фотографиями или настроить расписание.

Enter — отправить, Shift+Enter — новая строка. Без «Разрешить действия» помощник только читает данные.

Настройки ИИ

Модель по умолчанию

Переключить модель для следующего сообщения можно над перепиской.

Ollama на вашем компьютере или в локальной сети

Укажите адрес, по которому сервер Publikator может достучаться до Ollama, затем выберите модель из списка.

Модели будут получены с выбранного сервера автоматически.

Модель не появилась в списке?

Только для API, не поддерживающих список моделей. В обычной ситуации вводить имя не требуется.

OpenAI, DeepSeek и совместимые API

Выберите провайдер и введите его API-ключ. Сохранённое подключение появится в списке «Модель чата».

Подключить ChatGPT к Publikator

Плагин даёт внешнему чату инструменты Publikator. Выбирать модель встроенного чата можно во вкладках «Локальные модели» и «Облачные API».

Проверяем настройку сервера…

  1. В ChatGPT откройте «Плагины», нажмите «+» и добавьте собственный MCP-сервер.
  2. Вставьте адрес, выберите OAuth и укажите данные зарегистрированного OAuth-клиента.
  3. Войдите в Publikator и подтвердите нужные разрешения. Проверьте подключение командой «Покажи доступные проекты».
