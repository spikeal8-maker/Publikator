# Publikator

Publikator — единая self-hosted система автопубликации контента в Telegram, VK, MAX и Instagram.

## Принципы

- один репозиторий;
- один Docker-контейнер;
- один веб-интерфейс;
- одна SQLite-база в Docker volume;
- встроенный scheduler без n8n/Redis/RabbitMQ;
- публикация без изображения запрещена;
- состояние публикации хранится отдельно для каждой площадки;
- секреты интеграций шифруются ключом приложения;
- при сомнительном восстановлении после падения публикация не повторяется автоматически, чтобы не создавать дубли.

Проект находится в активной разработке. Архитектура и рабочий первый вертикальный срез добавляются в `main`.
